# Visite Barueri

Site turístico e informativo sobre Barueri, desenvolvido em HTML, CSS e JavaScript.

## Estrutura

- **Início:** index.html
- **Informações sobre Barueri:** história, curiosidades, quem somos e contato.
- **Locais turísticos:** Arena Barueri, Parque Dom José, Kartódromo Aldeia da Serra, Praça das Artes, Feira Noturna e Museu da Bíblia.
- **Galerias:** cada local possui galeria com navegação anterior/próxima.
- **Autenticação:** login, cadastro e recuperação de senha com Supabase.
- **Perfil:** edição de nome de usuário, nome completo, bio e foto de perfil.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Supabase
- GitHub Pages

## Observação

A página inicial possui uma versão visual documentada e não deve ter sua estrutura ou aparência alteradas sem uma solicitação específica.
